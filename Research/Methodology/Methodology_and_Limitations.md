# Methodology and Limitations

## Analytical Approach

Strength Intelligence uses a simple sequence:

1. Clean and standardize the data.
2. Build a recent baseline for each exercise.
3. Compare the current session with that baseline.
4. Add daily health context.
5. generate a finding.
6. Translate the finding into a possible action.
7. Show confidence and limitations.

## Baselines

A personal rolling baseline is preferred over a universal benchmark.

Example:

- Compare today's bench session with the user's previous five bench sessions.
- Compare sleep with the user's normal sleep range.
- Compare HRV with the user's own recent baseline.

## Correlation Is Not Causation

If stronger sessions happen after more sleep, that does not automatically prove sleep caused the improvement.

Other possible explanations include:

- Different exercises
- Different workout timing
- Food intake
- Stress
- Previous training load
- Motivation
- Measurement error

## Data Quality Risks

- Journal entries may be incomplete.
- Exercise names may be inconsistent.
- Apple Health may contain data from multiple devices.
- RPE is subjective.
- Small sample sizes can create unstable findings.

## Confidence Labels

| Label | Meaning |
|---|---|
| Low | Limited data or inconsistent pattern |
| Moderate | Useful pattern with some uncertainty |
| High | Repeated pattern with enough supporting data |

## Responsible Use

Strength Intelligence is for training decision support. It is not a medical device, injury diagnosis system, or substitute for professional care.
