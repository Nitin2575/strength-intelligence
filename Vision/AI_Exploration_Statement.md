# AI Exploration Statement

## Project Purpose

Strength Intelligence MkII is an educational and exploratory project.

It is intended to help me learn how AI can be applied responsibly to a real health and performance problem.

The project is not claiming that its recommendations are clinically validated or universally correct.

## What AI Does

AI may help with:

- Summarizing patterns
- Explaining calculated results
- Turning technical findings into plain language
- Helping users ask better questions
- Organizing relevant context
- Suggesting possible next steps for review

## What AI Does Not Do

AI should not:

- Diagnose injuries or medical conditions
- Invent metrics
- Hide uncertainty
- Replace deterministic calculations
- Present correlation as causation
- Give unsafe training advice
- Replace qualified professional judgment

## Core Principle

> The analytics system calculates. The AI explains.

This means:

1. SQL and Python calculate metrics.
2. Clear rules determine supported actions.
3. AI turns the structured result into understandable language.
4. The user can inspect the supporting data.
5. Limitations remain visible.

## Learning Questions

This project explores:

- How much context does an AI system need to provide useful advice?
- Which recommendations can be rule-based?
- Which insights require statistical analysis?
- How should confidence be communicated?
- How can AI avoid overstating weak evidence?
- What makes a recommendation feel trustworthy?
- When should the system say it does not know?

## Success

The project is successful if it helps me:

- Learn useful technical and product skills
- Understand my own training data more clearly
- Build a thoughtful health-related AI prototype
- Identify mistakes and limitations early
- Communicate the work honestly
