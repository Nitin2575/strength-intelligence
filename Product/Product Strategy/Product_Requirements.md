# Product Requirements

## Core User Need

A lifter wants to understand what is helping or limiting progress without manually comparing months of workout and health data.

## MVP Goal

Create a product that can:

1. Import normalized Apple Health data.
2. Import structured workout journal data.
3. calculate simple strength and consistency metrics.
4. Compare training performance with sleep and recovery signals.
5. Generate a clear session summary and recommendation.
6. Show the result in a polished frontend.

## Key User Stories

### As a lifter, I want to:

- See whether my major lifts are progressing.
- Understand why a session underperformed.
- Know whether I should progress or repeat a load.
- Compare performance across sleep and recovery conditions.
- Review evidence behind each recommendation.

## Main Screens

| Screen | Purpose |
|---|---|
| Overview | Show current status and major findings |
| Progressive Overload | Track progress by exercise |
| Fueling | Compare meal timing and nutrition with performance |
| Session Analysis | Explain one workout in detail |
| Insights | Surface patterns and opportunities |
| Methodology | Explain calculations and limitations |

## MVP Boundaries

The first version will use historical data and simple decision rules. It will not claim that correlations prove causation.

## Product Decision Rule

Every feature must answer at least one of these questions:

- What happened?
- Why might it have happened?
- What should the user do next?
- How confident are we?
